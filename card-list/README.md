# カードおつかいリスト

友人にカードを買ってきてもらうときの買い物リストです。ブラウザで開くだけで使え、ログインは不要です。

**URL:** https://kmtbk-tools.github.io/kamitsubaki-tcg-tools/card-list/

## 使い方
1. 「新しいリストを作る」で、カードの写真・名前・型番・欲しい枚数・予算（1枚あたり）・優先度・メモを登録
2. 「友人に送る」で、リスト画像（LINEの写真で送れる）とチェック用リンクを送る
3. 友人はリンクを開いて、買えた枚数・実際の値段・見つからなかったカードを記録し、「結果を送る」
4. 届いた結果のリンクを開くと、自分のリストに結果が入る

## 補足
- データは各自の端末のブラウザにだけ保存されます（サーバーには送りません）
- LINEのメッセージは5000文字までのため、写真がリンクに入りきらないときは名前と番号だけのリンクになります。写真はリスト画像で送ってください
- 写真もアプリの中で見せたいときは「写真入りファイル」を送り、友人は一覧の「写真入りファイルを開く」から読み込みます
